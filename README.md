# Undisputed

An offline body recomposition tracker for two people, built around the Tanita
DC-360 slip. Scan the slip on the phone or key it in; the reading happens on the
device.

This repository holds code only. Measurements live on each phone, and the
optional sync between the two phones goes through a separate private
repository that only its owners can see.

Published with GitHub Pages from the root of the `main` branch. After changing
any file, raise `VERSION` in `sw.js` so installed copies offer a restart.
